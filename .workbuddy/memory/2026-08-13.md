## 修复：每日计划模块删除二次确认弹窗显示在左下角
- 现象：dailyGoal 页点删除，`confirm()` 弹窗不居中、出现在页面左下角。
- 根因：`showConfirmDialog` 是函数式调用，其依赖的 `.van-popup--center` 居中 CSS 不被 `@vant/auto-import-resolver` 打进产物（与 Toast 同坑）；`dialog.scss` 之前只补了卡片视觉、漏了定位，`.van-dialog` 退化成文档流元素，teleport 到 body 后落在 `#app` 之后 = 页面左下。
- 修复：`src/styles/dialog.scss` 的 `.van-dialog` 加 `position:fixed; top/left:50%; transform:translate(-50%,-50%); z-index:2001`；`bounce` 入场/退场动画 transform 改为 `translate(-50%,-50%) scale(.94)` 防瞬移。
- 验证：vue-tsc ✅、vite build ✅；dist 中 `.van-dialog` 已带居中定位；已 `rm -rf + cp` 同步进 `native/android/app/src/main/assets/offline`。真机需 Android Studio 重打包 APK（或 `npm run dev` 手机访问电脑IP:5173 快速验证）。
